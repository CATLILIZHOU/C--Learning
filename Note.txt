C语言转化为及其可以执行的形式要经历三个步骤
1. 预处理（Preprocessing）：首先程序会被送交给预处理器，预处理器会执行以#开头的命令（通
常称为指令）。预处理器有点类似于编辑器，它可以给程序添加内容，也可以对程序进行修改。
2. 编译（Compilation）：修改后的程序现在可以进入编译器了。编译器会将预处理后的代码转换为
汇编代码，然后进一步转换为机器码。然而此时的程序还是不能运行的
3. 链接（Linking）：在这个阶段，链接器会将生成的机器码与所需的库文件链接起来，生成可执行
文件。

由于预处理器通常会和编译器集成在一起，人们甚至不会注意到它在工作。

简单程序的一般形式：
指令

int main(void)

   语句
}                                （C语言极其依赖缩写和特殊符号）

我们把预处理器执行的命令称为指令，这里暂时只关注#include指令。
C语言不同于其他的编程语言，它没有内置的“读”和“写”功能。C语言的输入输出功能是通过调用
库函数来实现的。库函数是由其他程序员编写好的函数，已经被编译成了机器码，存放在库文件中。
我们只需要在程序中调用这些函数，就可以实现输入输出功能。

函数分为两大类，一种是库函数，另一种是用户自定义函数。库函数是由其他程序员编写好的函数，
已经被编译成了机器码，存放在库文件中。我们只需要在程序中调用这些函数，就可以实现输入输出
功能。用户自定义函数是由程序员自己编写的函数，可以根据需要进行定义和调用。

函数仅仅是一系列组合在一起并且赋予了名字的语句

C语言规定每条语句都要以分号结尾，除了后面遇到的复合语句外

每个变量都必须有一个类型。类型用来说明变量所存储的数据的种类。
现在先只限定于两种类型范围内：int类型和float类型。
类型会影响变量的存储方式以及允许对变量进行的操作。
数值型变量的类型决定了变量所能存储的最大值和最小值，同时也决定了是否允许在小数点后出现数
字。

int可以存储整数，但有最大值214783647.
float可以存储比int大得多的数值，而且可以存储带小数位的数。但也有缺陷：进行算术运算时，其
速度通常比前者慢。而且其所存储的数字往往只是实际数值的一个近似值。

在使用变量之前必须对其进行声明。为了申明变量，首先要指出变量的类型，然后说明变量的名字。
例如：int height,lenghth,width;
      float profit,loss;
赋值时可以这么写：int height;
                  height = 8
当我们把一个包含小数点的常量赋给float型变量，最好在该常量后面加一个字母f，不加f可能会引
发编译器警告。

混合类型赋值也行，但不一定安全。

%d仅用于int型变量，若是float型变量，则应使用%f。
默认情况下%f会显示小数点后6位数字。若要改变显示的位数，可以在%f前加上一个点号和一个数字。
例如%.2f表示显示小数点后两位数字。

当程序开始执行时，某些变量会被自动设置为零，而大多数变量则不会。没有默认值并且尚未在程序
中被赋值的变量是未初始化的。

简化：变量声明和初始值： int height = 8

上述数值8是个初始化式
在同一个声明中可以对任意数量的变量进行声明和初始化，但必须是同一类型的变量。

在任何需要数值的地方，都可以使用具有相同类型的表达式。

获取输入使用scanf函数

#define _CRT_SECURE_NO_WARNINGS //忽略安全检测，不然使用scanf会报错
上述是使用scanf函数时的一个常见做法，尤其是在使用Visual Studio等编译器时。这个宏定义可以
避免编译器对scanf函数的安全性进行警告。
或者是使用scanf_s函数，它是scanf函数的安全版本，要求在输入字符串时提供缓冲区的大小，以防
止缓冲区溢出。不过貌似只有微软编译器支持。
注意&在scanf函数中是必需的，目前在此是比较难解释.

定义常量的名字
当程序含有常量时，建议给这些常量进行命名。可采用宏定义的特性给常量命名。
例如 #define INCHES_PER_POUND 166

这里的#define是预处理指令。

此外还可以利用宏来定义表达式：#define RECEPTIONAL_OF_PI (1.0f / 3.14159f)

当宏包含运算符时，必须用括号把表达式括起来。

在编写程序时，需要对变量、函数、宏和其他实体进行命名。这些名字称为标识符。

关键字不能作为标识符使用。

printf函数被设计用来显示格式串的内容。
格式串包含普通字符和转换说明，其中转换说明就是用字符%来做开头。表示待填充的占位符。

C语言编译器不会检测格式串中转换说明的数量是否与输出项的数量相匹配。且请注意顺序。

在转换说明%10.2f中，m是10，p是2，而X是f
最小字段宽度m指定了要显示的最少字符数量。如果要显示的数值所需的字符数少于m那么值在字段内
是右对齐的。即在值前面放置额外的空格。如果要显示的数值所需的字符数大于m，那么字段宽度会
自动增加以适应数值。
精度p的含义比较难描述，因为它依赖于转换说明符X的选择。

对数值来说最常用的转换说明符有以下几个：d,e,f,g。d用于显示整数，e用于显示科学计数法表示
的浮点数，f用于显示小数点表示的浮点数，g用于根据数值的大小选择使用e或f格式。
但是在现实非常大或者非常小的数时，说明符g会转换成指数形式以便减少所需的字符数。
